# Open-model benchmark (dropped 2026-11-25)

JP dropped the idea of running Inkling 2 Small (and other open models) as a benchmark beside the frontier models: in the pilot it found 22 to 68% of Neon's primary numbers and none of its quotes on the longest paper, and was not worth the time. The spec is kept here in case open models become competitive later. The shadow code was removed from `lives_run.py`; `models.json` still lists Inkling in case it is wanted again.
