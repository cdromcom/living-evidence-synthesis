### Limitation

All four LLMs were accessed via their public web-based chat interfaces at the time of the study (May 2025). Newer or more advanced versions available through paid subscriptions or API access may outperform the tested models on QUADAS-2 assessment. This means the findings reflect the performance accessible to users without specialized API access or subscription tiers.
