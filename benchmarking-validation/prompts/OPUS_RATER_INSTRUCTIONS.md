# Instructions given to each Claude Opus 5.5 rater (Claude Code subagent, model `opus` = claude-opus-5-5)

Six subagents rated EVD 1-13, 14-26, 27-39, 40-52, 53-65 and 66-77 (batches A-F); a seventh re-rated EVD 21 and 38 after the quote-parser fix. Each was started cold (no conversation context) with this text, with only the batch changed:

> You are one of several independent raters in a blind benchmark of how well AI models judge evidence nodes (EVDs) from a living evidence synthesis. You are rating EVDs <batch>. Work ONLY inside the blind folder (a copy of `packets/` with the same fields the other models see, plus `PROMPTS.md` and `fidelity_examples.json`). Do NOT read any other file or folder on this computer, do NOT browse the web, do NOT use any spreadsheet or Google tools, and do NOT look at other raters' output. Blindness is the point of the study; if you cannot judge something from the folder's contents, say so in the reason instead of looking elsewhere.
>
> For EACH EVD in your batch make four independent judgments using exactly the rubrics in PROMPTS.md: (1) relevancy: p_relevant (0-1), Relevant if >= 0.5; (2) fidelity (skip EVD 1-3, the worked examples): JP's gist rule, probabilities for Met / Partially Met / Unmet summing to 1, judged from the EVD statement and quote text only; (3) quote: whether the quote screenshot(s) show the quoted text word for word (a wrong page number does not matter), probabilities for Correct / Partially Correct / Incorrect / Missing / NA summing to 1, plus p_screenshot_shows_quote; (4) table: only if the packet has a table/figure screenshot (otherwise null; the Missing rule is applied in code). View every PNG with the Read tool. Judge each EVD on its own. Label = the option with the highest probability. Keep each reason to at most 25 words.
>
> Write one JSON file per EVD: `{"evd": N, "relevancy": {"label","p_relevant","reason"}, "fidelity": null or {"label","probs","reason"}, "quote": {"label","probs","p_screenshot_shows_quote","reason"}, "table": null or {"label","probs","reason"}}`.

The blind folder contained `packet.json` files without the `citekey`, `pdf`, `description_other_text` and `methods_context` fields. The subagents could list the output folder, so they could see other raters' file names but were told not to open them. Raw outputs are in `results/opus_raw/` (the original EVD 21 and 38 files, written before the parser fix, are in `results/opus_raw_superseded/`). `opus_to_results.py` converts them to `results/opus.r1.jsonl`.

Opus 5.5 was run as Claude Code subagents, not through the Messages API, so its inference settings (effort, temperature) are those of the Claude Code subagent runtime and are not recorded. Token counts and durations per batch are in `opus_usage.json`.
